# Contributing to Ordinata

The Ordinata source is available for inspection and evaluation under [LICENSE](LICENSE). It is not open-source software, and outside code contributions are not being accepted at this time.

Bug reports, numerical test cases and documentation corrections are welcome as issues. Include the Ordinata version, your operating system and a synthetic example; do not attach real measurement data.

Report security problems privately as described in [docs/SECURITY.md](docs/SECURITY.md).
