# Ordinata

Ordinata is a local linear inverse-problem and uncertainty workbench. It turns a bounded weighted linear calibration problem into a portable, tamper-checkable evidence bundle without presenting fitted estimates or synthetic samples as measurements.

Implementation is being built against [PRODUCT-SPEC.md](PRODUCT-SPEC.md). This repository is private for release review; sales and public distribution are not active.
